System Architecture

Engineered for 8GB Apple Silicon hardware. Perfect privacy, zero background CPU drain, and sub-500ms latency.

1. The Audio Layer (Ears)

Finalized & Audited
  • Wake Word: livekit-wakeword (ONNX) running silently at ~1% CPU.
  • STT: whisper.cpp (tiny.en) optimized for Metal framework for ~100ms processing.
  • Buffer: Python 300ms ring buffer to guarantee no dropped syllables.

2. The Perception Layer (Eyes)

Finalized & Audited
  • Capture: Apple ScreenCaptureKit via Swift bridge. 0ms sampling, 0% CPU footprint.
  • Fast Vision: Apple Native OCR executing on Neural Engine in ~30ms.
  • Deep Vision: YOLOv11-Nano via CoreML for UI element detection without triggering swap memory.

3. The Decision Layer (Brain)

Architecture Planned
  • Micro-Router (Edge): Featherweight NLP slicing semantic boundaries in ~2ms for offline commands.
  • Macro-Planner (Cloud): Routing complex logic to Claude 3.5 Sonnet / Gemini 1.5 Pro for structured JSON sequential payloads.

4. The Execution Layer (Hands)

Architecture Planned
  • Global Sandbox: macOS Quartz framework synthesizing true hardware-level HID inputs.
  • State Resolution: AppKit monitoring active frontmost windows for exact target disambiguation.

5. GCSP Security Sandbox (Firewall)

Architecture Planned

A strict interception layer separating the Macro-Planner from Execution. Validates all proposed UI actions against security policies to mitigate Indirect Prompt Injection, preventing malicious web text from triggering terminal operations or data extraction.
